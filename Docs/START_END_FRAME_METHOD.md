# START & END FRAME METHOD — Franco's ruling, 2026-07-29
### The plate-generation plan for Worlds 1–4. **Read this before generating a single frame.**

---

## 1. ❌ My five-plates-per-world idea was wrong

I proposed that shot N's end frame IS shot N+1's start frame when the action is continuous — dropping
W1–W4 from 32 plates to 20. Franco:

> **"Do not reduce it to five plates per world. That is mostly a trap."**
>
> *"The action may be continuous, but the camera usually changes at every cut. Shot 1's end frame might
> be a low rear angle. Shot 2's start frame might depict the same instant from a lateral wide angle.
> **Same story moment, different image.**"*

Because each shot is its own SD2 clip, **every shot needs its own start plate.** End plates are optional
only where we don't care where the motion lands — and in this reel nearly every shot has a designed
handoff, pose, formation, cover position, car angle or occlusion.

> **The saving is in shared blocking and geometry, not final image count. Build once, then translate
> that action state into the next camera angle.**

**Budget: 32 final plates for W1–W4, plus ~3 temporary geometry/seam masters.** If two or three
forgiving shots turn out not to need end anchors, treat that as a bonus, **not the production plan**.

---

## 2. End frames: **fully finished, selectively strict**

> *"Do not make them loose. **A loose end frame gives SD2 permission to drift precisely where we need
> control.**"*

**The rule: hard on geometry, softer on ephemera.**

| Lock hard | Leave softer |
|---|---|
| Positions, pose, limb geometry, camera, scale, horizon | Muzzle-flash shape |
| Formation, cover position, car angle, occlusion | Road grit, dust particulate |

⚠ **The endpoint must be physically reachable from the start within the shot's duration.**
> *"A gorgeous but impossible endpoint will produce limb warping, teleporting, or rushed motion."*

That makes reachability a **design constraint on the end plate**, checked against the bar count — our
shots run 1.875 s to 5.625 s, so a 1-bar shot cannot travel far.

---

## 3. Match cuts: **one shared geometry master, TWO finished images**

> *"A literal single file cannot serve both sides because the content is different."*

My instinct (one shared image) was half right — the **geometry** is shared, the **image** is not.

### W1 → W2 · the kickflip seam
| Side | Content |
|---|---|
| **W1 end** | skate Paola · skateboard · urban clothes · SoCal street |
| **W2 start** | Bollywood Paola · sari · **no skateboard** · market |

**Method:** generate the **W1 kickflip apex first**, then use *that exact image* as the
**transformation source** for W2's start plate.
**Change ONLY:** wardrobe, prop, environment.
**FREEZE:** pose · crop · camera · scale · horizon · hands · knees · vertical position.

### W3 → W4 · the grip-to-wheel seam
**Lock the over-the-shoulder version.**
- **W3 end:** camera behind Paola, two-handed gun grip aimed forward.
- **W4 start:** same shoulder line, same elbows, same hands — grip becomes the wheel.

---

## 4. Order: **seams first, then work inward**

> *"Do not generate all sixteen starts first."*

| # | Build | Why |
|---|---|---|
| **1** | W1 S4 end + W2 S1 start | the kickflip seam |
| **2** | W3 S4 end + W4 S1 start | the grip→wheel seam |
| **3** | W2 S4 end + W3 S1 start | **occlusion transition, not a pose match** — the fabric-to-industrial-plastic *motion* must agree |
| **4** | W4 S4 exit | a **neutral dust / chrome-flare** exit so it can become World 5 **without depending on the kimono colour** |

Then **one world at a time**, building each shot's start and end **together**, testing reachability and
continuity as you go: W1 pair → test → next pair → finish W1 → then W2, W3, W4.

---

## 5. 🚧 THE GATE — do not manufacture 32 plates before testing SD2

> *"First build **one complete seam pair and one representative normal shot**, then run a **720 test**.
> That tells us whether SD2 prefers our end plates exactly as finished, or whether backgrounds need
> simplifying before we scale production."*

**This is the most important line in the ruling.** Building all 32 against an untested assumption risks
rebuilding all 32. **Three plates → one 720 test → then scale.**

---

## 6. The pink kimono pays off here

Franco, on the W4→W5 exit now that the kimono is ruled pink:

> *"That makes the neutral silver-dust or blade-like flare out of World 4 especially useful, because it
> can resolve into **moonlight on pale pink silk** without forcing an indigo colour bridge."*

The neutral exit was already the right call; the pink ruling makes it easier, not harder.
